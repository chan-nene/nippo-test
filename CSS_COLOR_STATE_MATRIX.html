NIPPO / CROSS-PAGE CONSOLIDATION

同じ役割を、同じ行で比べる。

日報・設定・管理の現在値を横並びにし、差を残すか、どの共通tokenへ統合するかを判断するための表です。

比較のルール

同じ役割なら統一します。似ていても役割が違うものは、基礎tokenだけ共有し表現差を残します。右端が推奨する統一後です。

–比較する役割
–統一候補
–差を残す
日報 → 設定 → 管理 → 統一案
読み方： BG＝背景色、FG＝文字・アイコン色、BD＝枠線色です。transparentは「透明」で、背後の面色がそのまま見える状態を市松模様で示します。Focus ringとDisabledは独立した色比較にせず、各要素の状態として掲載します。Disabledの統一方針は、opacityに頼らずsoft背景・muted文字・通常borderを明示することです。統一案は検討材料で、CSS本体には未反映です。
